# A股抄底/潜伏多维技术分析 Skill (stock-bottom-fishing)

输入股票**名称或代码**，一键完成 18 个维度的技术体检，输出"是否适合抄底/潜伏"的结构化结论。

## 分析维度

| 类别 | 指标 |
|---|---|
| 超跌信号 | TD 神奇九转（绿9/红9、计数延长）、BIAS 乖离率、位置（距 60/250 日高低） |
| 动能指标 | MACD(12,26,9)、KDJ(9,3,3)、RSI(6/12/24)、WR(14)、CCI(14) |
| 趋势指标 | DMI/ADX(14)、均线系统(MA5/10/20/30/60/120/250)、BOLL(20,2) |
| 量能与资金 | OBV、量比(5日/20日)、主力资金流(近5/10日净流入)、筹码分布(获利比例/平均成本/90%成本区) |
| 多周期 | 日线 + 周线 MACD/KDJ 共振、MACD 底背离检测 |
| 风险度量 | ATR(14) 日均波幅（用于止损距离） |

## 神奇九转（TD Sequence）判定逻辑

- **买入计数（绿9）**：连续 K 线收盘价 < 4 根前收盘价，计满 9 根为"底部9"
- **卖出计数（红9）**：对称，收盘价 > 4 根前收盘价连续 9 根
- 计数 1-8 阶段任意一根不满足即清零重计；达到 9 后延续则进入"延长"（绿10/11…）
- **核心用法**：绿9 是转折预警，**不是买入指令**。可靠买点 = 绿9 + 次日/近期放量阳线确认（TD 9 后买阳不买阴）；极弱趋势中绿9 后常延长，裸绿9 视为下跌中继

## 安装

把本目录复制到你的 Trae 工作区：

```bash
mkdir -p <workspace>/.trae/skills
cp -r stock-bottom-fishing <workspace>/.trae/skills/
```

安装依赖：

```bash
pip install akshare pandas numpy --break-system-packages
```

## 使用

在 Trae 中直接说"分析 XX 能否抄底"，或手动运行：

```bash
python3 scripts/analyze_stock.py 600519      # 贵州茅台(代码)
python3 scripts/analyze_stock.py 贵州茅台     # 名称亦可
python3 scripts/analyze_stock.py 159558      # 支持 ETF
```

## 输出内容

- 实时行情快照（价格/涨跌幅/量比/换手/主力净流入占比）
- TD 九转近 12 日序列（标注绿9/红9）
- 日线全指标 + 周线共振 + 主力资金流 + 筹码分布
- 供上层（SKILL.md 判定框架）综合给出四档结论：
  强势买点（右侧确认）/ 左侧潜伏区 / 等待区 / 不适合（回避）

## 数据源与容错

东财 → 新浪 → 腾讯 三源自动回退，接口失败自动重试并标注；盘中实时数据优先东财，新浪/腾讯当日 K 线收盘后更新。
