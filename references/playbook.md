# 思考逻辑手册（playbook）

> 这是本技能的「大脑」。脚本负责给数，本文件负责**怎么想、怎么判、怎么说**。
> 读法建议：先看「三层漏斗」建立顺序，再看「十条原则」避免踩坑，最后用「四档判定矩阵」出结论。

## 一、三层漏斗：分析的固定顺序

**顺序错了，结论必错。** 同一根绿 9，在低位是机会、在半山腰是陷阱。

```
第 1 层：位置（Where）
   距 60 日低 +x% / 距 60 日高 -x% / 处于 MA120·MA250 上方还是下方
   → 先定性：低位区(<+20%) / 中位区(+20%~+50%) / 高位区(>+50%)
   → 位置决定后面所有信号的「解释权」

第 2 层：趋势（Which way）
   DMI(+DI vs -DI, ADX) / 均线排列 / 周线 MACD 与周 KDJ
   → 判：趋势未止（顺趋势思维）/ 趋势衰竭（转折思维）

第 3 层：动能与资金（Momentum & Money）
   日 MACD 柱方向 / KDJ / RSI·WR·CCI 超卖超买 / 量能 / 主力 5·10 日净额
   → 判：动能是否在改善、改善是否被资金确认

第 4 层：价位（Where to act）
   支撑·压力由近及远 + 参考止损 = 最近支撑 − 1×ATR
   → 没有价位支撑的结论是废话，"能不能买"最终要落到"在哪买、跌到哪认错"
```

**一句话记忆**：**先看在哪，再看往哪走，再看有没有劲，最后看在哪下手。**

**同一套漏斗在顶部/持仓侧镜像使用**：第 1 层改成看「涨到位没有」，第 2 层看「SAR 有没有翻空、SAR 在哪」，第 3 层看「超买与出货」，第 4 层看「在哪减、持有底线在哪」。四档矩阵、止盈触发器、顶背离口径见 §五。

### 补充维度（19~25）放在第 3 层，只做加权、不定结论

P1 从 MyTT/通达信原语库补入的 7 个维度（BBI / TRIX / ROC / VR / MFI / AR·BR / XSII，字段与解读见 `SKILL.md`）**全部归入第 3 层「动能与资金」**，因为它们回答的都是"劲还在不在、有没有换边"，而不是"在哪"。

三条硬规则：

1. **不单独定档。** 任何一个补充维度都不足以把某只票从「等待区」升到「左侧潜伏区」——升档仍然只认第 2 条原则（动能改善 + 量能确认 + 资金不逆，三者至少两个）。
2. **同向才加权。** 补充维度与主维度**方向一致**时才给结论加分：「ROC 极低位回升 + MFI 背离 + MACD 绿柱收窄」三者同向 = 动能层证据充分；「BBI 下穿后收回」若同时得到 MFI 抬高与 VR 地量佐证，则「左侧转强」的成色明显更足。
3. **矛盾时以主维度为准，并把矛盾写进风险。** 例：MFI14 < 20（量价双超卖，偏多）但主力仍放量净流出 → 以资金维度为准，结论不能算"偏多"，并要在报告的"风险证据"里点出这个矛盾，而不是只挑对自己有利的那个维度说。

**逐维度的判读要点（抄底语境）**：BBI 看"下穿后首次收回"（比 MA20 更钝、更少骗线）；TRIX 看"上穿 TRMA 且贴近 0 轴"（滤噪强但滞后大，金叉当日往往已走了几天）；ROC 看"-10% 以下的极低位回升"（超跌反弹前兆）；VR 看"< 40~70 的地量区"（下跌动能枯竭）；MFI 看"< 20 的量价双超卖"与"价新低而 MFI 抬高"；AR·BR 看"AR<60 且 BR<50 的人气冰点"；XSII 看"跌破 `xsii_dn2` 后收回"（极端超卖反抽）。

## 二、十条核心原则（反直觉清单）

1. **信号是统计事件，不是买入指令。**
   任何指标（MACD 金叉、TD 绿9、KDJ 金叉）只说明「发生了一类事」，**不说明「该买」**。必须用该股自身历史的同类信号中位收益 / 胜率 / 失败率来定权重 —— 这就是 `macd_stats.py` 存在的理由。

2. **单一指标不构成结论。**
   至少要有「动能改善 + 量能确认 + 资金不逆」三者中两个，才能从「等待区」升到「左侧潜伏区」。

3. **绿9 是预警，不是命令。**
   极弱趋势中绿 9 常延长为绿 10/11/12。可靠买点 = 绿9 + 次日或近期**第一根放量阳线**（买阳不买阴）。

4. **反弹日的主力流出最危险。**
   价格涨但主力净流出 = 借反弹出货。**当日净流出而 5 日净流入（背离）**尤其要标出来，说明「护盘的是过去的钱，今天的钱在跑」。

5. **量能可以放大信号，也可以证伪信号。**
   缩量下跌 = 抛压减轻但无承接（中性）；放量阳线 = 资金进场（强确认）；放量下跌 = 出货（强减分）；**极度缩量(<60%)下的上涨或横盘，不构成任何确认**。

6. **位置优先级高于一切超卖信号。**
   距 60 日低 +71% 的票出现超卖，是「高位回调」；距 60 日低 +5% 的票出现超卖，才是「底部区域」。同一个 RSI6=18，含义完全不同。

7. **周线是高度天花板。**
   日线再好，若周线 MACD 绿柱扩大、DIF 下行，反弹高度受限 —— 结论里要写「反弹空间受周线压制」。

8. **筹码告诉你阻力在哪，不告诉你方向。**
   获利比例高 = 浮盈盘多（有兑现压力）；获利比例极低 = 深套（抛压小但也没人接力）；现价低于平均成本 = 上方套牢盘密集。90% 成本区上沿是第一道真实压力。

9. **必须量化「等待成本」。**
   不要只说「等金叉」。「明日金叉需涨 20.3%，不可能；横盘则第 11 日、+1%/日则第 5 日」——这才是可决策的信息（`macd_path.py`）。

10. **数据缺失要诚实，且要说明影响方向。**
   资金流拿不到就说拿不到，并写「本次结论未纳入资金维度，可靠性下降」。**绝不用其他维度的数据去"补"缺失的维度。**

## 三、四档判定矩阵

出结论时，把四层漏斗的结果套进下表。**支持与反对势均力敌 → 一律「等待区」。**

| 档位 | 允许出现的条件 | 必须满足的硬条件 | 话术要点 |
|---|---|---|---|
| **强势买点（右侧确认）** | 绿9 或超跌形态修复 | 放量阳线站回 MA5 **且** 主力转净流入 **且** 日线动能转红 | 给介入区间 / 止损 / 分批计划 |
| **左侧潜伏区（可小仓试探）** | 底部结构好，绿柱收窄、KDJ 低位待叉、TD 绿9 出现在关键支撑上 | 缺右侧确认（量未放 或 资金未转） | 给「出现 XXX 才加仓」触发清单，仓位仅试探级 |
| **等待区（暂不参与）** | 部分信号偏多 | 关键确认缺失（资金仍流出 / 周线未稳 / 位置过高 / 极度缩量） | 明确「等什么」，给出观察价位 |
| **不适合（回避）** | 强负面主导 | 周线 MACD 绿柱扩大且 DIF 下穿 0 轴 / 放量破位创新低 / 主力连续大幅净流出 / 妖股退潮 / 高位红9 后放量滞涨 | 明确不建议，说明理由，不给介入价 |

**强负面（一票否决级）**：周线 MACD 绿柱扩大 + DIF 下穿 0 轴；放量破位创新低；主力连续大幅净流出；妖股退潮期。

**强正面**：日线 MACD 绿柱连续 5 日以上收窄；KDJ 低位金叉；TD 绿9 出现在关键支撑（MA120 / 前低 / 平台）上；MACD 底背离；放量阳线站回 MA5。

**补充维度的强正面（第 3 层的加分项，仍不单独定档）**：MFI14 < 20 且与第 14 维 DIF 背离同向；VR26 落入地量区同时价格止跌；BBI 下穿后首次放量收回；TRIX 上穿 TRMA 且贴近 0 轴；AR26 < 60 且 BR26 < 50 后 AR 上穿 BR。

## 四、MACD 金叉的正确用法（本技能新增的核心逻辑）

用户最常问「MACD 金叉了会反弹吗」。**标准答法分三步，缺一不可：**

1. **先验前提**：DIF > DEA 才叫金叉。DIF < DEA 时只能说「绿柱连续收窄 N 日」——**必须纠正用户前提，不能顺着说**。
2. **量化等待成本**（`macd_path.py`）：明日金叉所需涨幅 vs 该股 ATR 日波幅；不同速度下的金叉日与金叉价；上方压制由近及远。
3. **用该股自身历史定价**（`macd_stats.py`）：只统计 **0 轴下方**金叉（0 轴上金叉属强势延续，另当别论），分「全部 / 缩量 / 放量 / 深水区 DIF≤-0.3 / 浅水区」给胜率与中位收益。

**判读规则**：
- 10 日中位收益 ≈ 0 或再死叉率 > 60% → 该股此信号为**噪音**，不作为入场依据。
- 缩量组显著优于放量组（如缩量 10 日胜率 100% vs 放量 25%）→ 说明该股「缩量金叉更真」，需结合当日量比落到对应分档。
- 优先采信「与该股当前状态同档」的统计，而非「全部样本」的均值。

**结语模板**：金叉 ≠ 买点；该股历史上 0 轴下金叉 10 日中位 +x%，属<有效信号/偏噪音>；本次落点在<深水区/浅水区>+<缩量/放量>，历史同档表现……。

### 判定口径：金叉与背离都已原语化，别再手写判断

P2/P3 之后，金叉/死叉与底部背离都不再由上层脚本手写比较，而是由 `stock_lib` 的通达信原语产出固定字段。**判定与引用一律用字段，不要自己写 `dif[i] > dea[i] and dif[i-1] <= dea[i-1]` 这类比较**——手写版本在"连续两根相等"等边界上与原语定义不一致，会导致两处脚本对同一只票给出不同结论。

| 字段 | 含义 | 用法 |
|---|---|---|
| `macd_gc` / `macd_dc` | DIF 上穿 / 下穿 DEA 的当日标记 | 判定"今天是不是金叉日" |
| `macd_since_gc` / `macd_since_dc` | 距上次金叉 / 死叉的交易日数 | 回答"金叉几天了"，比"金叉了"信息量大得多 |
| `macd_gc60` | 近 60 日金叉次数 | 次数过多（如 ≥5）= 该股频繁穿叉，信号偏噪音 |

**底部背离（第 14 维）的口径也已升级**：现在先用 `t_llvbars` 原语识别"左右各 5 根都不低于它"的**摆动低点**（`swing_lows`，相邻过近的低点合并为一簇），再比较最近两个摆动低点的**价格新低 vs DIF/柱抬高**（`divergence`）。

由此带来两条与旧版不同的读法：
- **"仅 1 个摆动低点，结构不充分"是合法结论**，不是数据缺失。样本不足时**不许退化成"看 60 日最低点"来硬造一个背离**。
- 背离的成色分档已经内置：`（柱同步抬高，强度更好）` > `（柱未同步，强度一般）`。**柱没同步抬高的背离要降权**，别和"价跌 DIF 抬 + 柱也抬"同等看待。

## 五、逃顶四档镜像矩阵与止盈体系

抄底那套漏斗**上下颠倒着用**就是逃顶。核心差异只有一个：**信号方向反转，读法词也要跟着反转**——`macd_stats.py --side top` 输出的"跌率"就是抄底侧的"胜率"，"破 MA20"就是"收复 MA20"，"再金叉"就是"再死叉"。

### 顶部三层漏斗（与 §一 严格镜像）

```
第 1 层：位置（Where）—— 涨到位了吗
   距 60 日低 +x% / 距 250 日最高回撤 -x% / 是否仍在 MA120·MA250 上方
   → 高位区(>+50%) 且距 60 日高 <5% = "仍在顶部，结构未坏"
   → 距 250 日最高已回撤 >25% = "顶部大概率已过，进入下跌段或筑底段"
   位置依然优先：低位区的超买是"启动"，高位区的超买才是"逃顶"

第 2 层：趋势（Which way）—— 趋势线还在不在
   SAR 抛物线（本技能新增，唯一自带"移动止损线"语义的维度）：
     SAR 在价格下方 → 多头持有期，SAR 就是移动止盈/止损线，收盘不破就拿着
     SAR 在价格上方 → 空头/离场期，SAR 是压力线，站上它才谈重新做多
     由多转空那根（sar_flip）= 教科书式离场信号
   DMI 是否换边 / 均线是否走平拐头 / 周线 MACD 红柱是否收窄

第 3 层：动能与资金 —— 劲还在不在
   MACD 红柱收窄·0 轴上死叉 / TD 红9 / J·CCI·WR·RSI6·MFI 超买 / BIAS24 正乖离
   量能：放量滞涨 = 出货；缩量新高 = 无接力
   主力：当日大额净流出且 5·10 日由正转负 = 趋势性撤离

第 4 层：价位（Where to act）—— 在哪减、在哪认错
   压力位（levels() 的 resistances） = 分批减仓参考
   SAR 值 = 移动止盈线；两者取更近者作为"持有底线"
```

### 顶部四档镜像矩阵

出结论时与 §三 同样套表。**支持与反对势均力敌 → 一律「持仓观察」。**

| 档位（镜像说法） | 允许出现的条件 | 必须满足的硬条件 | 话术要点 |
|---|---|---|---|
| **顶部确认（理应离场）** | 冲高收阴 / 高位放量滞涨 | 收盘跌破 SAR **或** 跌破「最近支撑−1×ATR」；且伴随主力转净流出 **或** 0 轴上死叉与顶背离同现 | 明确给"减/清"比例与执行价，不给"再看看" |
| **顶部警示（减仓保护）** | 超买/顶部标签 ≥3 项（J>80 / CCI>100 / WR<20 / RSI6>80 / MFI>80 / BIAS24>15% 中任意组合） | 未跌破 SAR，趋势未坏（SAR 多头持有期） | 给"冲高减 X 成、跌到 X 元再减"的分批计划，保住浮盈 |
| **持仓观察（持有但不加）** | 仅 MACD 红柱收窄 / 距 250 日最高已回撤 >20% | 未出现 0 轴上死叉、未破 SAR | 写明"等什么变坏再动"，并给出 SAR 具体数值 |
| **趋势健康（继续持有）** | 无标签或标签 ≤2 项 | SAR 多头持有期 + 日线红柱扩大 + 主力不逆 | 只在跌破 SAR 时才需重新评估，不必天天找顶 |

**必须纠正的两个直觉**：
1. **"超买 ≠ 要跌"**。强势股 J 值可以在 80 上方钝化数周。只看标签数量会把你甩下车——**标签只用于"减仓保护"，不用于"清仓判顶"**。
2. **"红9 ≠ 顶"**。红 9 之后常继续红 10/11/12。可靠变盘 = 红9 + **次日或近期第一根放量阴线**（卖阴不卖阳，与抄底侧"买阳不买阴"镜像）。

### 顶部信号的历史复盘怎么读（`macd_stats.py --side top`）

两套口径各跑一套表（`0 轴上方死叉` 与 `TD 红9`），**方向词全部反转**：

| 字段 | 抄底侧读法 | 顶部侧读法 |
|---|---|---|
| 5 / 10 日胜率 | 上涨的比例 | **下跌的比例**（跌率） |
| 触 MA20 | 是否收复 MA20 | **是否跌破 MA20** |
| 再死叉 | 金叉后再死叉（信号失效） | **再金叉**（多头夺回主动 = 信号失效） |

**判读规则**：
- 10 日跌率 ≈ 50% 或再金叉率 > 60% → 该信号在这只票上是**噪音**，只当提示、不单独作为离场依据。
- 「0 轴上死叉」优先看 **高位区 DIF≥+0.3** 与 **放量** 两个子样本：放量+高位的死叉最凶；缩量贴 0 轴的死叉常常只是换手。
- 「TD 红9」优先看 **DIF>0（强势中）** 子样本：涨势中的红9 常是"中继"，跌率反而偏低；DIF≤0 时的红9 才是真压制。
- **优先采信与该股当前状态同档的子样本**，而不是"全部样本"。

### 顶背离的口径（与 §四 的底部背离严格镜像）

同样先用 `t_hhvbars` 原语识别"左右各 5 根都不高于它"的**摆动高点**（`swing_highs`，相邻过近的高点合并为一簇），再比较最近两个摆动高点的**价格新高 vs DIF 走低**（`divergence_top`）。
- **"仅 1 个摆动高点，结构不充分"是合法结论**，不许退化成"看 60 日最高点"硬造一个顶背离。
- 顶背离**只在高位区（距 60 日低 >50%）才有意义**；中低位出现的"高点走低 + DIF 走低"多数只是上升中继的洗盘。
- 判定与引用一律用 `divergence_top()` / `top_signals()` 的字段，**不要自己写 `high[i] < high[j] and dif[i] > dif[j]`**（理由同 §四）。

### 止盈体系（把浮盈变成规则，而不是手感）

三档工具，与 `levels()` 的压力位复用同一套数据：

1. **SAR 移动止盈线（首选）**：现价在 SAR 上方时，SAR 就是移动止盈线。它随行情自动抬升，**不需要预测顶部**，只要求执行"收盘跌破就走"。这把"何时卖"从判断题变成了执行题。
2. **压力位分批止盈（辅助）**：用 `levels()['resistances']` 由近及远的压力（前高 / 90% 筹码上沿 / BOLL 上轨 / XSII 大通道上轨 / 整数关口）分 2~3 批减仓，每批写明触发价与比例。
3. **ATR 保护性止损（兜底）**：若 SAR 因连续暴涨被推到很远（距现价 >15%），说明 SAR 给的空间过大，改用「最近支撑 − 1×ATR」兜底，避免单根长阴回吐过多浮盈。

**三个止盈触发器（任一触发即执行，不再临时商量）**：
- 收盘跌破 SAR；
- 0 轴上死叉 **且** `divergence_top` 明确构成顶背离；
- 高位（距 60 日低 >50%）+ 超买/顶部标签 ≥3 项 + **当日主力大额净流出**（借高位出货）。

**最后一条纪律**：止盈计划必须在**买入时就写下**，不是涨到心慌才临时定。报告若给了买入建议却没给止盈触发器，视为不合格输出。

## 六、持仓处置决策树（`holdings_check.py` 的规则映射）

```
拿到横向表与标签后，逐只按顺序判：

0) 收盘跌破 SAR？              → 是：SAR 是事前约定的移动止盈线，按纪律先减/离场
1) 现价 ≤ 参考止损？           → 是：按纪律先减/离场（无条件优先）
2) 现价距止损 < 3%？           → 是：逼近止损，跌破即减仓，停止加仓
3) 浮亏 ≤ -12%？               → 是：必须处理（先定去留，再谈补仓）
4) 高位标签（距60日低>50% / 冲出BOLL上轨 / J>100 / TD红7+）+ 当日主力流出？
                               → 是：优先保护浮盈，冲高减一部分
5) 跌破MA20 + 极度缩量 + OBV下行？ → 是：结构走坏但无量，持有观察，不加仓
6) 站上MA20 + 放量 + 主力转正？    → 是：可持有待涨，回踩不破可小仓加
```

**纪律高于预测**：止损位是事前约定的，不是事后商量的。报告里必须写出数字。

## 七、风险标签表（与 `holdings_check.py` 的规则引擎、`stock_lib.top_signals()` 的顶部标签一一对应）

**口径归属（重要）**：本表分两段维护 —— **顶部/超买侧**（TD红9 起至 SAR 翻空）由 `stock_lib.top_signals()` 唯一定义，`analyze_stock.py` 的 `[顶部信号]` 块与 `holdings_check.py` 的标签都**只读不算**（`stock_lib.analyze()` 算一次挂在 `a['top']`，两个消费方共用）；**其余项**（TD绿9、CCI/RSI6 超卖、位置、趋势、量能、资金、筹码、盈亏）由 `holdings_check.tags_for()` 维护。**改阈值只改 `top_signals()` 一处**，禁止在渲染层再写一遍超买线。

| 标签 | 触发条件 | 含义 |
|---|---|---|
| TD红9(变盘预警) | 卖出计数 ≥ 9 | 顶部转折预警，涨势可能生变 |
| TD红n(接近9) | 卖出计数 7~8 | 接近变盘区，需提高警惕 |
| TD绿9(转折预警,需放量阳确认) | 买入计数 ≥ 9 | 跌势可能耗尽，**须放量阳线确认** |
| J超买>100 | J > 100 | 短线严重过热 |
| J超买区>80 | 80 < J ≤ 100 | 短线偏热 |
| CCI超买>100 / CCI超卖 | CCI >100 / <-100 | 顺势通道突破 / 超跌 |
| RSI6超卖 | RSI6 < 20 | 极端超卖 |
| 距60日低%+x%(高位) | 距 60 日低 > 50% | **位置最高优先级信号** |
| 跌破MA20 | 收盘 < MA20 | 中短期趋势转弱 |
| 冲出BOLL上轨 | 收盘 > 上轨 | 超涨，短线易回踩 |
| 极度缩量 x% | 5日/20日量比 < 60% | 无量，任何上涨都不构成确认 |
| 明显放量 x% | 5日/20日量比 ≥ 150% | 需结合涨跌判断是进场还是出货 |

| 浮亏x% | -12% < 盈亏 ≤ -8% | 亏损扩大中 |

| WR超买<20 | WR14 < 20 | 短线超买（WR 越小越超买） |
| RSI6超买>80 | RSI6 > 80 | 短线极端过热 |
| MFI超买>80(量价双超买) | MFI14 > 80 | 带量资金推到极端，量价双超买 |
| BIAS24正乖离x%(偏离过大) | BIAS24 > 15% | 偏离 24 日均线过远，均值回归压力 |
| 冲破XSII大通道上轨 | 收盘 > `xsii_up2` | 冲出自定义大通道上沿，反抽风险高 |
| VR26过热>250 | VR26 > 250 | 成交量比率过热 |
| AR26人气过高>150 | AR26 > 150 | 人气/情绪指标过热，见顶前兆 |
| MACD红柱收窄(顶背离前兆) | 柱 > 0 且 前柱 > 当前柱 | 上涨动能衰减（顶部侧偏空，与"绿柱收窄"镜像） |

## 八、标准作业流程（SOP）

**分析单只（抄底/潜伏）**
1. `analyze_stock.py <代码>` 跑数。
2. 判位置（第 1 层）→ 判趋势（第 2 层）→ 判动能资金（第 3 层）→ 抄关键价位（第 4 层）。
3. 从 `report-template.md` 模版 A 填表。
4. 按四档矩阵定档，写触发清单 + 失效条件。
5. 加免责句。

**分析持仓**
1. `holdings_check.py <代码:成本>...`（可 `--detail`）。
2. 先看大盘快照，再看横向表，最后逐只走决策树（§六）。
3. 用模版 B 出报告；**先讲纪律（止损），再讲观点**。

**判断该不该卖 / 逃顶**
1. `analyze_stock.py <代码>` 看 `[顶部信号]` 块：超买标签数、SAR 值与持有期、距 60·250 日最高回撤、0 轴上死叉、顶背离与摆动高点。
2. `macd_stats.py <代码> --side top` 用该股自身历史定价（0 轴上死叉 / TD 红9 两套表，看跌率与再金叉率）。
3. 按 §五 顶部四档镜像矩阵定档；**支持与反对势均力敌 → 「持仓观察」**。
4. 给出 SAR 具体数值 + 分批止盈价与比例（复用 §五 止盈体系三档工具）。
5. 复查出口径：不因"超买标签多"就喊清仓（标签只做减仓保护），不因"红9"就说见顶（须放量阴线确认）。
6. 加免责句。

**回答「MACD 金叉了会涨吗」**
1. 验前提（是否真金叉）。
2. `macd_path.py` 量化等待成本。
3. `macd_stats.py` 用历史分档定价。
4. 用模版 C 出报告。

**任何标的存在以下特征，报告开头即加高风险警示**：连续涨跌停妖股、PE 显著高于行业、已发风险警示公告、谐音概念炒作、上市 <60 日新股、北交所(4/8 开头)。

**关于数据降级：按标注处理，不要重跑。** 数据层已内置缓存、限流冷却、等待预算与主机熔断（见 `troubleshooting.md` §九/§十），遇到 `[过期缓存,可能滞后]`、`腾讯` 源、筹码为 `None`、某维度缺失时：

1. **照常出报告，并在结论里写明"本维度未纳入 + 对可靠性影响方向"**（第 10 条原则）。
2. **不要为了凑齐数据反复重跑脚本。** 冷启动基准 ≈8s、四脚本冷缓存 ≈12.4s；若某次明显慢于基准，是数据层正在执行冷却（对的行为），重跑只会把冷却越推越远。
3. **只有连缓存都拿不到数据（报"日K所有数据源均失败"）才是真故障**，此时按 `troubleshooting.md` §八 排查网络与代理，而不是继续在本技能里循环重试。

## 九、常见认知陷阱（自查用）

| 陷阱 | 正确做法 |
|---|---|
| 用户说"金叉了"，直接顺着分析 | 先验证 DIF 是否真的 > DEA，不成立就纠正 |
| 看到超卖就说"底部" | 先看位置，高位超卖 ≠ 底部 |
| 看到绿9 就说"可以买" | 绿9 是预警；须放量阳线确认，须查是否延长 |
| 用"全部样本"均值回答个股问题 | 用与该股当前状态同档的子样本 |
| 缩量上涨当成"洗盘结束" | 极度缩量下的上涨无确认意义 |
| 只给方向不给价位 | 每个结论必须落止损数字 |
| 拿 5 日主力净流入对冲当日流出 | 明确指出背离，背离本身是风险信号 |
| 数据取不到就跳过不提 | 标注缺失 + 说明对结论可靠性的影响 |
| 看到 MFI 超卖 / VR 地量就喊底 | 补充维度只在与主维度**同向**时加权，不单独定档 |
| 见到"背离"二字就当底部确认 | 背离只在"两个摆动低点"间成立；"仅 1 个摆动低点"是结构不充分，不许拿 60 日最低点硬造 |
| 自己写 `dif > dea and 前一日 dif <= 前一日 dea` 判金叉 | 直接用 `macd_gc` / `macd_dc` / `macd_since_gc` 字段，手写版在边界上与原语不一致 |
| 数据缺了就反复重跑脚本凑齐 | 按降级标注出报告；重跑只会把限流冷却越推越远（见 §八 末） |
